# AI 駆動開発のための Vue 学習教材

## この教材の前提

この教材は、**コードの大半を AI に書かせる前提**で Vue フロントエンド開発を学ぶためのものです。
そのため、次のような内容は**扱いません**。

- 行レベルの文法（`v-for` の書き方、`ref` の細かい API など）
- 1 文字ずつの写経

代わりに、AI 駆動開発で**人間が判断・指示しなければならない層**に絞ります。

- **方針・設計判断** — Composition API を使う／状態管理ライブラリを入れない、といった「何をなぜ選ぶか」
- **ツール選定** — Vite / Vitest / ESLint / Prettier / Orval / MSW などを「各カテゴリで何を選び、どう組み合わせるか」
- **コマンド運用** — `npm run dev` / `build` / `generate:api` などのワークフロー
- **ベストプラクティス** — 生成物を触らない、型で守る、モックの固定／ランダム使い分け、AI への指示の出し方
- **認証・認可** — AI でもつまずきやすい領域。実プロジェクト（ShogiProject）のパターンを示す

> なぜこの切り口か：AI はコードを書けますが、「どの技術を選ぶか」「どういう構成にするか」「どのコマンドをいつ叩くか」は人間が決めて指示する必要があります。AI 駆動開発の生産性は、**この判断と指示の質**で決まります。文法を覚えるより、ここを押さえるほうが費用対効果が高い、という考えに基づいています。

## 想定読者

- 他言語（Python / Java / Go など）でのプログラミング経験がある
- Vue / モダンフロントエンドは初学

Vue の文法そのものは説明しませんが、「なぜこの構成なのか」は経験者が腑に落ちるように説明します。

## 体験を重視する

各章には**実際に手を動かす演習**があります。ゼロから最小サンプルアプリを組み立て、コマンドを叩いて挙動を確かめます。読むだけでなく、必ず手元で動かしてください。

## 章構成

| 章 | テーマ | 手を動かす内容 |
|----|--------|----------------|
| [00_setup.md](00_setup.md) | 環境とプロジェクトの作り方 | `npm create vue` で雛形生成、起動 |

| [02_tooling.md](02_tooling.md) | ツール選定 | Vite/Vitest/ESLint/Prettier を入れて動かす |
| [03_commands.md](03_commands.md) | コマンド運用 | dev/build/test/lint のワークフロー |
| [04_schema_driven.md](04_schema_driven.md) | スキーマ駆動とモック | Orval + MSW で API を自動生成・モック |

`sample-app/` には、章を通じて作る最小サンプルの完成形スニペットを置いています。詰まったら参照してください。

## 進め方

1. [00_setup.md](00_setup.md) から順に読む
2. 各章の「演習」を手元で実行する
3. 「ShogiProject ではこうしている」という囲みで、実プロジェクトの該当箇所を確認する

それでは [00_setup.md](00_setup.md) から始めましょう。
